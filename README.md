# SmartPrice

Calculadora web simples que ajuda a calcular o preço de venda de um produto, feita com HTML, CSS e JavaScript.

**Demo:** https://rafatorresdev.github.io/SmartPrice/

## Tecnologias

HTML  
CSS  
JavaScript

## Como executar

Basta abrir o arquivo `index.html` no navegador, sem dependências adicionais.
